# Vue Demo

Vue 3 演示应用，展示 Toolkit House 包和组件。

## 功能

- Apollo Client for GraphQL
- Composition API
- 响应式状态管理
- @toolkit-house/vue-components
- @toolkit-house/ts-utils

## 安装

```bash
cd apps/vue-demo
pnpm install
```

## 开发

```bash
pnpm run dev
# http://localhost:5174
```

## 构建

```bash
pnpm run build
pnpm run preview
```
