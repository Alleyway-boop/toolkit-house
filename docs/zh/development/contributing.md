# 贡献指南

欢迎为 Toolkit House 做出贡献！

## 开发流程

1. Fork 仓库
2. 创建功能分支
3. 进行更改
4. 运行测试和类型检查
5. 提交 PR

## 代码规范

### TypeScript

- 使用 ES2022 特性
- 遵循严格模式
- 添加 JSDoc 注释

### 命名规范

- 文件：`kebab-case.ts`
- 变量：`camelCase`
- 常量：`UPPER_SNAKE_CASE`
- 类型/接口：`PascalCase`

### 提交消息

```
feat: 添加新功能
fix: 修复 bug
docs: 更新文档
```

## 测试

为所有新功能编写测试。
