# 简介

Toolkit House 是一个现代化的前端工具包 monorepo，为开发者提供高质量的工具和组件。

## 概述

Toolkit House 提供以下功能：

- **完整的工具链**：从开发到部署的一站式解决方案
- **多框架支持**：React 19、Vue 3、Svelte、SolidJS
- **类型安全**：完整的 TypeScript 支持和严格类型检查
- **Monorepo 架构**：统一管理所有包和应用的依赖关系
- **现代化构建**：使用 Vite 和 unbuild 实现快速构建

## 包含内容

### 工具包

- **@toolkit-house/ts-utils** - 综合性 TypeScript 工具库
- **@toolkit-house/validation** - 类型安全的验证库
- **@toolkit-house/http-client** - 现代 HTTP 客户端
- **@toolkit-house/logger** - 轻量级日志库
- **@toolkit-house/security** - 安全工具
- **@toolkit-house/realtime** - 实时通信工具

### UI 组件

- **@toolkit-house/react-components** - React 19 组件库
- **@toolkit-house/vue-components** - Vue 3 组件库

### 演示应用

- **React Demo** - 全栈 GraphQL 演示
- **Vue Demo** - Vue 3 Composition API 演示
- **Svelte Demo** - Svelte 演示应用
- **SolidJS Demo** - SolidJS 演示应用
- **API Gateway** - GraphQL API 网关
- **Go Server** - Go 后端服务

## 技术栈

- **构建工具**: Vite、unbuild
- **包管理**: pnpm workspaces
- **类型系统**: TypeScript 5.3+
- **代码质量**: ESLint、Prettier
- **测试**: Vitest
- **文档**: VitePress
